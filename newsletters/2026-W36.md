# Microsoft Foundry Weekly — 2026-W36

_2026-07-01 to 2026-08-31 · 9 updates_

## 🚀 New features
- **Claude tool-use capabilities on Azure** — Structured outputs, web search, web fetch, an MCP connector, and tool search are now available for Claude models hosted on Azure in Foundry, turning a model endpoint into a production agent platform. ([source](https://devblogs.microsoft.com/foundry/five-new-claude-capabilities-now-available-in-foundry))
- **Toolboxes** — group MCP tools and OAuth2 user-delegation auth behind one versioned endpoint, so Foundry handles per-user token isolation, consent, and refresh instead of agent code. ([source](https://devblogs.microsoft.com/foundry/building-agents-that-act-on-your-behalf-with-toolboxes-in-foundry))
- **Agent Framework SDK (C#, Python)** — a unified multi-agent orchestration SDK that consolidates patterns previously split across AutoGen and Semantic Kernel. ([source](https://azure.microsoft.com/updates?id=564312))
- **Tracing for Microsoft Agent Framework** — public preview adds tracing for Python and .NET, showing how agents reason, call tools, and interact with models during execution. ([source](https://azure.microsoft.com/updates?id=564071))
- **GenAI telemetry protection** — public preview stores generative AI content in a dedicated GenAIContent table (AppGenAIContent in Log Analytics) in Application Insights, letting teams apply access controls to sensitive Foundry telemetry. ([source](https://azure.microsoft.com/updates?id=567594))
- **Document PII playground** — public preview sample in the Foundry NextGen portal runs a prepared document through Azure AI Language's document-based PII detection and shows the redacted output. ([source](https://azure.microsoft.com/updates?id=563331))
- **Content Understanding CU 2.0** — public preview adds synchronous Read/Layout APIs, semantic chunking for retrieval, new prebuilt analyzers, and agentic document reasoning for complex extraction. ([source](https://devblogs.microsoft.com/foundry/azure-content-understanding-updates-august-2026))

## 🧠 Models
- **Added:** GPT-5 series (GPT-5.5 down to GPT-5, standard/mini/nano) — broader support in Content Understanding's refreshed CU 1.0 GA API and the CU 2.0 preview, cutting inference token use up to 28% and improving confidence-score accuracy (AUROC) up to 14% in internal evaluations. ([source](https://devblogs.microsoft.com/foundry/azure-content-understanding-updates-august-2026))
- **Added:** GPT-5.6 — now generally available via Model Serving Endpoint in Azure Databricks, purchased through Microsoft Foundry. ([source](https://azure.microsoft.com/updates?id=567431))
