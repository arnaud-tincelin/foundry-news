# Microsoft Foundry Weekly — 2026-W48

_2026-11-16 to 2026-11-23 · 14 updates_

## 🚀 New features
- **Hosted agents networking (Ignite)** — shared subnet IPs, private CA trust, network egress controls, deployment to your own AKS clusters, plus resilient execution and memory snapshots for hosted agents in Foundry Agent Service. ([source](https://devblogs.microsoft.com/foundry/hosted-agents-foundry-agent-service-ignite-2026))
- **Browser Automation Tool** — enterprise-ready cloud browsers for Foundry agents, with MCP action batching, Live View/Take control, session recording, VNet injection, browser proxy, profile reuse, secret management, and CAPTCHA handling. ([source](https://devblogs.microsoft.com/foundry/browser-automation-tool-ignite))
- **Tools and Toolboxes** — build a tool once and reuse it across a whole fleet of production agents instead of re-integrating and re-documenting it per agent. ([source](https://devblogs.microsoft.com/foundry/build-once-reuse-across-your-agent-fleet-tools-and-toolboxes-in-foundry))
- **Continuous improvement** — Foundry feeds agent traces and user input back into the system, tests improvements, and shows quality/speed/cost trade-offs before you ship a change. ([source](https://azure.microsoft.com/en-us/blog/continuous-improvement-comes-to-microsoft-foundry))
- **Microsoft Copilot harness in Foundry Toolkit for VS Code** — public preview; Agent Builder supports prompt agents on the Copilot harness, with tool/skill config, local YAML editing, and deploy-to-Foundry. ([source](https://azure.microsoft.com/updates?id=581468))
- **Programmed Training** — public preview API for running your own post-training loop over open-weight models, for teams whose needs outgrow managed training jobs; access via sign-up form. ([source](https://azure.microsoft.com/updates?id=581713))
- **Multi-turn evaluation** — public preview; assess a complete agent conversation against quality standards, not just individual responses. ([source](https://azure.microsoft.com/updates?id=581746))

## ✅ Preview → GA
- **Governance policy guidance** — now generally available in Foundry Canvas and the Foundry Toolkit for VS Code, surfacing relevant policies and warnings for agent types, models, toolboxes, and guardrails as you build. ([source](https://azure.microsoft.com/updates?id=581463))
- **Foundry Dev Pack** — now generally available; installs the Foundry developer tools (editor, terminal, coding-agent support) on your machine in a single install. ([source](https://devblogs.microsoft.com/foundry/the-foundry-dev-pack-is-here-build-foundry-agents-your-way))
- **Foundry Managed Compute** — now generally available; serve 150+ open models on dedicated NVIDIA or AMD GPUs, with Global, US, and EU Data Zone deployments. ([source](https://devblogs.microsoft.com/foundry/managed-compute-ga))
- **Business Applications in Work IQ** — now generally available in Microsoft Foundry; adds CRM/ERP records to agent grounding, reducing custom integration work. ([source](https://azure.microsoft.com/updates?id=579680))
