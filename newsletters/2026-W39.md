# Microsoft Foundry Weekly — 2026-W39

_2026-09-01 to 2026-09-25 · 8 updates_

## 🚀 New features
- **Network egress controls for hosted agents** — public preview lets you attach an outbound policy (allow/deny rules by FQDN) to a hosted agent in Foundry Agent Service and audit calls before enforcing them. ([source](https://devblogs.microsoft.com/foundry/egress-controls-hosted-agent))
- **Foundry Dev Pack** — one-command installer (`winget`/`brew`/`curl`) that sets up Foundry CLI tools, the VS Code extension, and Foundry guidance for coding agents. ([source](https://devblogs.microsoft.com/foundry/foundry-devpack-announcement))
- **Azure AI Speech LLM 2607** — improves multilingual and mixed-language recognition, cuts latency up to 3x versus 2605, and adds a dedicated phrase-list parameter for domain vocabulary. ([source](https://devblogs.microsoft.com/foundry/announcing-azure-ai-speech-llm-2607))

## ✅ Preview → GA
- **Routines in Foundry Agent Service** — now generally available: managed timer, recurring, and event-based triggers (e.g. GitHub issues, Teams messages) to run agents automatically, plus a preview reminder tool for agents to resume long-running work. ([source](https://devblogs.microsoft.com/foundry/from-chatbots-to-automated-assistants-routines-in-microsoft-foundry-are-now-generally-available))
- **Enable/disable controls for Foundry agents in Agent 365** — now generally available; admins can enable or disable a Foundry agent object from the Agent 365 governance surface in Microsoft Admin Center. ([source](https://azure.microsoft.com/updates?id=571826))
- **Publishing Foundry agents to Microsoft 365 Copilot and Teams** — now generally available, giving Foundry developers a native path to ship agents to those surfaces. ([source](https://azure.microsoft.com/updates?id=571816))

## 🧠 Models
- **Added:** GPT-6 Sol and GPT-6 Luna — now generally available in Microsoft Foundry alongside GPT-6 Astra; Sol targets production agents and complex workflows, Luna is a smaller/faster model for high-volume tasks like extraction and routing. ([source](https://azure.microsoft.com/en-us/blog/gpt-6-astra-sol-and-luna-for-production-agents-in-microsoft-foundry))
- **Added:** Claude Opus 5.5 — now available in Microsoft Foundry for long-running coding and knowledge work. ([source](https://techcommunity.microsoft.com/blog/azure-ai-foundry-blog/claude-opus-5-5-comes-to-microsoft-foundry-for-long-running-coding-and-knowledge/4558051))
